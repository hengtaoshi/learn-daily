# 面试题库 · 编写规范（每课必守）

> **唯一标准，每写一课先看它。**
> **核心一条：题库文件只保留四部分 —— 课题 / 母题索引 / 问题清单 / 参考答案，其余一律不写。**

适用范围：`面试题库/` 下所有题库文件。

## 1 · 文件与命名

| 项 | 规定 |
| --- | --- |
| 位置 | `面试题库/` |
| 命名 | `第 N 课 · 课程名 · 面试题库.md`（课程名与学习日志一致） |
| 索引同步 | 每新增一份，在 [学习日志.md](../学习日志.md) 「面试题库」表加一行：题量 / ★★★ / 🔧 / ☆ |

## 2 · 文件结构（四部分，顺序固定）

| # | 部分 | 写法 |
| --- | --- | --- |
| 1 | **课题** | 首行 H1：`# 第 N 课 · 面试题库（课程名）` |
| 2 | **母题索引** | `## 母题索引` + 表：`| 母题 | 一句话 | 覆盖题号 |` |
| 3 | **问题清单** | `## 问题清单` → `### A 组 · xxx` → 每题一行 `- [ ] **N.** 【标记】题目` |
| 4 | **参考答案** | `## 参考答案` → `### 【标记】N · 标题` → 答案正文 |

**禁止写进题库**：用法说明、评级口径、依据表、诚实声明、统计小计、格式说明、自测记录表、附录、缺口清单、进度信息。
**依据统一记在本文件第 5 节「依据库」**，既不丢溯源，又不占题库版面。

## 3 · Markdown 硬规则

| 元素 | ✅ 正确 | ❌ 错误 | 后果 |
| --- | --- | --- | --- |
| 问题行 | `- [ ] **21.** 【★★★】问题` | `【★★★】21. 问题` | 标记挡行首 → 不认列表项 → **整组合并成一段** |
| 答案标题 | `### 【★★★】21 · 标题` | `【★★★】### 21 · 标题` | `###` 不在行首 → 标题失效 |
| 分组标题 | `### A 组 · 包管理` | 把小计塞进标题 | 标题要能被大纲识别 |

**标记（`【…】`）永远放在语法元素之后，绝不放在行首。**

## 4 · 四级标记

| 标记 | 含义 | 判定标准 |
| --- | --- | --- |
| **★★★ 必背** | 面试高频 **且** 生产真遇到 | 面经/真题命中，**或**事故复盘里的直接根因 |
| **★★ 理解** | 会问，但偏浅或属追问中段 | 面经出现过，通常不是主问题 |
| **🔧 生产必会** | **企业天天用，面试很少直接问** | 有明确生产场景，面试频率低 |
| **☆ 了解** | **不是面试题** | 教学/习惯性内容，标出来免得白背 |

★★★ 必须能对上第 5 节依据库；对不上就降级。教学自造题一律 ☆。

## 6 · 排序规则（用户明确要求）

```text
★★★ 必背  →  ★★ 理解  →  🔧 生产必会  →  ☆ 非面试题
```

每组内部按星级降序；同级按题号升序；**题号永不重排**（排序只改显示顺序，答案区仍按题号对应）。

## 7 · 数量与用法

- 每课**上限 30 题**，低频题折叠成一行。
- 必须有**母题索引**：几十题 → 几个原理；**背母题，不背题**。
- **三轮过滤法**：① 逐题口述并勾选 ② 只做没勾上的 ③ 考前只看 ★★★。
- `- [ ]` 勾选框就是自测记录，不另设自测表。

## 8 · 交付前自检清单

```text
[ ] 只有四个部分：课题 / 母题索引 / 问题清单 / 参考答案
[ ] 列表项数 == 题号总数
[ ] 答案标题数 == 题号总数
[ ] 没有以【…】开头的残留坏行
[ ] 没有 > 引用的说明段、统计行、附录
[ ] 每道 ★★★ 都能对上依据库
[ ] 组内已按星级降序
[ ] 母题索引覆盖到每一题
[ ] 学习日志.md 索引表已同步
[ ] 在渲染视图里实际看过一眼
```
