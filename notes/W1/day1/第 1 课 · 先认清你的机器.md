# 第 1 课 · 先认清你的机器

## 1：systemd-detect-virt

该命令是在问机器一句话“你是真身，还是分身？”

输出：none--->物理机

输出：kvm / vmware / oracle / microsoft--->虚拟机

## 2.lsblk -f

lsblk=list block devices，列出所有“块设备”（硬盘，分区，U盘，光驱），-f 让它顺便告诉你每块的文件系统类型。

想象硬盘是一块地，这条命令告诉你：这块地被切成了几块、每块盖的是什么类型的房子（ext4 / ntfs / swap）、每块房子挂在哪个门牌上。

输出要盯三个地方：

看什么    说明
FSTYPE 列    Ubuntu 根分区应该是 ext4
MOUNTPOINT 列    根分区挂载点是 /（一个斜杠）
有没有 ntfs    有 ntfs 分区 = 你在双系统（那是 Windows 的地盘）
顺手把根分区那一行的 SIZE（容量）记下来，下一课要用。
