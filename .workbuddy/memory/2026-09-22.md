### 踩坑记录（重要，避免复发）

- **给题目加行首标记破坏了 Markdown 语法**：写成一行的 `【★★】1. 问题` → 行首不再是 `1.`，Markdown 不认列表项，**整组被合并成一个段落**；答案区的 `【★★★】### 14 ·` 同理让标题失效。用户反馈"四组题目糊成一团、没有格式"。
- **修正与规范**：问题行必须是 `- [ ] **N.** 【标记】文本`；答案标题必须是 `### 【标记】N · 标题`。

- **批量脚本要限定区域**：加标记的正则 `^\d+\.` 误伤了附录「三个连环问」的 1./2./3.，已回退。

## 任务四：文档转 PDF（用户："字体缩小点，转 PDF 要 9 页太多了"）

- **关键认知**：字号不在 md 里，由导出工具决定 → 直接做导出管线，而不是改 md 内容。
- 管线：`pdf/md2html.mjs`（自写 md→HTML，零外部依赖）→ Chrome 无头 `--print-to-pdf`。
  样式：`pdf/print.css`（9pt 基线）/ `pdf/print-8pt.css`（8pt + 9mm 边距）；一键脚本 `pdf/export.ps1`。
- **页数**：第 2 课题库 9pt 单栏 7 页 → **8pt 双栏 4 页**；第 1 课 **3 页**；学习日志 **4 页**（单栏）。
- 环境事实：本机**无 pandoc / wkhtmltopdf**，有 Chrome + Edge（无头打印）与 Node。
- 两个操作坑：① 生成脚本里的正则含反引号，写进模板字符串会截断 → **生成脚本一律用 String.fromCharCode(96)**；
  ② 清理用的正则 `/-(双栏|8pt|8pt双栏)\.pdf$/` **把要保留的 8pt 成品一起删了**，且目标文件被占用时 unlink 报 EBUSY
  → **清理白名单要显式列举，不要用模糊后缀匹配**。

### 补充（用户偏好）：PDF 只用小字号，不要双栏

- 用户原话：**"只是所字体缩小不要搞两行排列，字体缩小就行，页数没有硬性要求"**。
- **PDF 一律单栏**，省页只靠字号（默认 8pt）与页边距，**禁止再用 column-count 双栏**。
- `pdf/export.ps1` 默认 `-Cols 1`；`pdf/print.css` 里的 `body.cols2` 规则保留但不启用。

### 补充（用户偏好）：PDF 字号定为 9pt

- 用户问"字体现在是多大，可以稍微大一点" → 原来 8pt，现改为 **9pt（小五号）**，仍单栏。
- 预设文件：`pdf/print-9pt.css`（默认）/ `pdf/print-8pt.css`（更小）/ `pdf/print.css`（9pt 宽松行距）。
- 字号对照：六号 7.5pt ＜ **8pt** ＜ 小五号 **9pt** ＜ 五号 10.5pt（Word 常規正文）。
- `pdf/export.ps1` 默认 `-Preset pdf\print-9pt.css`、`-Cols 1`。

### 补充：★ 标记加粗（字体回退修正）

- 现象：`★`(U+2605) 微软雅黑无此字形 → 浏览器回退到符号字体，**标记看起来比正文小**，而标记恰恰是最该被看见的东西。
- 修法：`md2html.mjs` 的 inline() 把 `【★★★|★★|🔧|☆】` 包成 `<span class="mk">`；`print.css` 加 `.mk{font-weight:700;font-family:"Segoe UI Symbol","Noto Sans Symbols 2",...}`。
- 代价：标记变宽 → 页数各 +1（学习日志 5 / 第 1 课 4 / 第 2 课 6）。用户已明确"页数没有硬性要求"，故接受。

- 新增 **记忆三档**：必须脱手（每课 5~8 条）/ 可查 / 认识即可。
- 新增 **闭卷阶梯 L0→L3**：**第一遍只需到 L1（会说）**，L2 在第二三遍，L3 到月末。
- 新增 **20 分钟最低可完成版**：读讲义 5 → 挑 3 条手打 5 → 闭卷重敲 7 → 记一行 3。
- 新增 **间隔重复**：当天不死磕；D+1 默写、D+3、D+7 各过一遍；**同一条闭卷 3 次仍想不起来 = 原理没懂，回来问我**。

### 教训（写入教学约定，后续每课遵守）

1. **闭卷单位必须是"一条命令"，不是"一课"。**
2. **标准要低到"今晚一定做得完"** —— 宁可让他天天有完成感，也不要给一个完不成的完美计划。
3. 学员说"记不住"时，第一反应是**检查我自己给的标准是否过高**，而不是要求他更努力。
4. 零基础阶段要主动区分"必须背"和"可以查"，**不许默认全部都要脱手**。

### 三个坑（已修，别改回去）

1. **`.ps1` 必须 UTF-8 带 BOM**：否则 Windows PowerShell 按 GBK 读，中文正则变乱码（`绗瑊0}璇?`），脚本解析直接失败。
2. **必须 `--user-data-dir` 独立配置目录**：用户开着 Chrome（DSH GUI 就在浏览器里）时，无头实例共享默认 profile 会**静默退出、不产出 PDF**。
3. **必须 `Start-Process -Wait -RedirectStandardError` 调 Chrome**：直接 `&` 调用时 Chrome 往 stderr 写的 `DEPRECATED_ENDPOINT` 警告会变成 `NativeCommandError`，被 Stop 策略掐断；用 `*> $null` 又会不产出。
